# Mobile Repair · بسته‌ی سرور تعمیرگاه

این مخزن **فقط برای رساندن بسته‌ی سرور به سرور خود تعمیرگاه‌ها** است. کد منبع اینجا نیست و منتشر نمی‌شود.

- فایل `….tar.gz.enc` **رمزشده** است. کلیدش فقط داخل دستور نصب یک‌بارمصرفی است که مدیر تعمیرگاه از پنل تعمیرگاه («سرور تعمیرگاه») می‌گیرد.
- `setup.sh` فقط سیستم را بررسی می‌کند، بسته را دانلود و باز می‌کند و نصب‌کننده‌ی داخل آن را اجرا می‌کند.

این فایل‌ها را مستقیم دانلود نکنید؛ دستور نصب را از پنل تعمیرگاه بگیرید.
